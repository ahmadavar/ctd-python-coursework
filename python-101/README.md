# Python 101 — Code the Dream

Coursework from the foundational Python program at Code the Dream.

## What's covered

- Core Python programming (functions, loops, conditionals, OOP)
- CSV file processing and data cleaning
- Database operations with SQLite
- Data analysis and visualization
- Web applications with Streamlit

## Structure


- **Assignments 1–3**: Core Python programming exercises
